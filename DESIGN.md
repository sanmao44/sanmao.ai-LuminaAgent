# SANMAO.AI 2026 Visual Direction

## World

SANMAO is a professional creative cockpit with two complete, deliberately tuned themes. Light mode uses cool paper, clear ink and saturated violet for focused work in bright studios; dark mode uses deep graphite, lifted neutral surfaces and a softer violet for long sessions in dim rooms. Both share semantic status colors and keep Super Canvas as the single luminous product signal.

## System

- Desktop-first: stable 64px rail, 64px topbar, centered work area and fixed composer.
- Typography: one UI sans stack with 14px body, 13px controls and 12px captions.
- Rhythm: a 4px spacing base, compact 8px controls and 12px work surfaces.
- Surfaces: quiet neutral fills and low-contrast borders; in light mode use surface contrast before shadow, reserving short soft shadows for floating tools. Avoid stacked colored cards.
- Motion: 160-220ms ease-out for focus, selection and task state; no decorative entrance choreography.
- Accessibility: shape-following focus rings, keyboard-first controls, semantic status announcements and no color-only state.

## Action Hierarchy

One primary action per region. Agent send and generation actions use the accent fill. Model, web, skill and reference controls are quiet secondary controls. Super Canvas remains a high-salience highlighted entry because it is a core product differentiator.
