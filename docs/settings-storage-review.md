# 设置页与图片存储排查（2026-10-13）

结论：应用图片库与浏览器额外保存都有用途，但原界面将两种不同的存储操作混在同一行，默认路径说明已过时，并存在目录切换后历史图片无法读取的问题。

## 操作的真实含义

| 操作 | 作用位置 | 保存方式与影响 |
| --- | --- | --- |
| 保存图片库路径 | 运行 SANMAO.AI 的电脑 | 新图片使用已保存的目录；已有文件不搬移；相对路径按服务进程工作目录解析并保存为绝对路径 |
| 恢复默认 | 运行 SANMAO.AI 的电脑 | 清空自定义配置，使用默认图片库；启动环境变量可以覆盖默认目录 |
| 打开已保存目录 | 运行 SANMAO.AI 的电脑 | 打开已保存的位置，不使用输入框里的未保存草稿；局域网访问也作用于服务器电脑 |
| 选择额外保存目录 | 当前浏览器所在电脑 | 浏览器获得目录授权后，在生成图片归档时另存一份；不改变应用图片库，不复制已有图片 |
| 停止额外保存 | 当前浏览器 | 清除已保存的目录授权引用，不再开始新复制；已经开始写入的批次会完成 |

普通默认目录是用户目录下的 `.sanmao-ai/media/images`。`SANMAO_IMAGE_STORAGE_PATH` 与 `SANMAO_MEDIA_ROOT` 可以改变其位置；旧版 `.data/images` 与项目同级的 `image_generation_records` 是历史读取/迁移来源。浏览器目录选择需要支持 File System Access API 的安全上下文，通常为 Chrome/Edge 的 localhost 或 HTTPS。

## 已确认并修复的问题

1. **两个目录概念混用。** 原“选择本地目录”不会填入图片库路径。新界面分别说明“应用所在电脑”和“当前浏览器”，额外保存提供停止入口。
2. **默认路径说明错误。** 原卡片写 `.data/images`，而存储适配器已经使用固定的用户级媒体库。新文案说明普通默认目录、启动覆盖与旧目录兼容。
3. **切换路径后旧图片断链。** 原读取候选可能遗漏默认根及旧自定义目录。现在始终包含默认根，保存前持久登记旧/新自定义根；这些根只用于读取回退，不触发启动时的历史素材复制。
4. **保存成功不代表目标可写。** 原设置只保存字符串。现在先创建目录并实际写入专属探针，清理探针后才保存；权限、空间或历史目录登记失败时保留旧设置。
5. **打开目录与实际保存目录解析不一致。** 原打开操作使用未解析的配置字符串，并在进程创建失败前就返回成功。现在复用相同的绝对目录解析和既有文件夹打开适配器，等待启动/错误事件，成功仅表示已发出打开请求。
6. **浏览器额外保存静默失败。** 原逻辑下载服务商原始链接、跳过非成功响应、把部分格式统一命名为 PNG。现在优先使用已经归档的应用链接，按 MIME 保存，继续处理可保存的图片并汇总失败；并发批次使用不同文件名。
7. **长任务使用旧目录选择。** 生成过程中停止或更换额外保存目录，原异步闭包仍可能使用启动时的目录。现在复制开始时读取当前目录引用。
8. **联网测试/保存期间可丢失草稿。** 处理中继续输入 Key 或切换服务商，会被旧请求结果清空或覆盖。现在请求期间禁用相关编辑，并在按钮上明确新 Key 测试成功会保存。

## 设置页布局

五个分类为偏好、联网、存储、备份、维护，默认展示偏好。分类按钮显示当前选择，内容保持挂载以保留草稿。服务重启归入维护；版本、端口与构建信息放入可展开详情。布局适配窄屏，沿用主题 tokens，改善正文、辅助文字和键盘焦点。

## 边界与验证

- `components/settings/SettingsWorkspace.tsx` 和 `ImageStorageSettings.tsx` 只负责展示与交互。
- `lib/browser-image-directory.ts` 是浏览器 Blob/文件适配器；目录引用仍通过现有 `client-history` 存取。
- 应用图片路径通过现有设置 Repository 写入；媒体路径与历史根仍由现有媒体适配器维护。
- API 的认证边界和 LAN 管理员权限保持现有行为；没有新增持久化或业务状态 owner。
- `app/page.tsx` 仍保留设置状态、请求连接、备份恢复与通知 composition；封板后的 Legacy Integration Surface 没有整体重写。
- 行为测试覆盖分类切换、草稿保留、保存/打开回调、目录切换与重启读取、不可写目标、登记失败、迁移过滤、模拟进程打开、浏览器权限与部分保存失败。
- `npm run check` 通过：类型检查、更新清单、2086 项测试与生产构建；2 项系统语音测试因 Windows 当前安全上下文不可用而跳过。`git diff --check` 通过。
- 新构建在浏览器中验证了浅色/深色、1305px 桌面与 390px 窄屏；真实路径草稿在分类切换后保留，窄屏存储区无水平溢出。

## 真实限制

- 修复不能自动推断此前已经丢失记录的旧自定义目录。历史根注册表沿用最多 24 个目录的上限。
- 真实浏览器目录授权、用户磁盘写入和系统文件管理器窗口没有用自动化触发；这些路径使用隔离目录或 mock 验证。
- 备份恢复、日志清理和服务重启没有为本次 UI 验证执行。
