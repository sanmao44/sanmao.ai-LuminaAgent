# 音色录音导入与音效排查（2026-11-24）

## 本地修复

- 克隆录音读取元数据后，原实现先清空音源并调用 `load()`，再读取 `duration`；浏览器此时已将时长重置。现在先保存时长，再卸载事件并释放播放器与临时 URL。主界面与超级画布共用此组件。
- 上传兼容 Windows 的 MP3/WAV MIME 别名，以及 MIME 缺失或通用二进制类型的音频。扩展名只用于选择候选格式，仍验证字节签名与文件大小。
- ElevenLabs 音效时长改为项目统一下拉菜单：0.5 秒及整数秒，v2 上限 22 秒、v3 上限 30 秒，默认 5 秒。非法小数会被 Contract 拒绝。
- 音效输出按任务保存的模型信息标记为“音效”，不再误标“音乐/曲目”，不提供歌曲续写操作。明确的模型白名单拒绝在主界面与画布显示中文处理说明。

修复沿用现有 Contract、上传 Application、Provider Adapter 和 UI 共享组件，没有新增持久化或任务生命周期 owner。

## 实际音效异常与边界

- 原 v2 任务的上游状态为完成，返回模型为 `elevenlabs-sound-effects-v2`，但其音频经独立 Gemini 转写得到“科技 UI 点击。”，符合用户反馈的朗读问题。此前另一转写模型返回空文本，不能据此认定音效正确。
- 原 v3 任务的上游错误明确说明当前 API 密钥的模型允许列表不包含该模型。本地无法替服务商授予调用权限，也未修改密钥权限。
- 一次额外 v2 短时长请求只提交一次、返回一个输出；这只能验证提交与取回链路，不能证明音效内容正确。

v2 的内容异常仍需服务商核查实际路由/生成结果。不能将其描述为已修复，也不能通过改字段、自动换模型或不断重复扣费来掩盖。v3 需使用已授权连接或由账户持有人调整服务商的允许列表。

## 克隆配音 422：语速兼容（追加排查）

用户登记音色后，`voice-clone-tts` 朗读报 HTTP 422，错误指出语速与所选设置不兼容。

本轮复核当前型号 JSON、详细章节、公开定价与官方调试器：都仍将语速标为 0.5–2，ElevenLabs 为 0.7–1.2，未披露 Qwen3 / Chatterbox 的额外条件。文档也声称不需要在登记时选择引擎。这些说明与实际接口行为有冲突。

使用既有音色与同一短句进行有限实测，没有重新登记音色：

- Qwen3 显式传 `engine=qwen3, speed=1`：HTTP 422，与用户截图相同。
- 同一请求仅省略 `speed`：HTTP 200，返回 12,168 字节 MP3。
- Chatterbox 传 `speed=1`：同一语速兼容错误。
- ElevenLabs 两档使用普通登记音色：上游明确拒绝，称需要 ElevenLabs 登记的音色。此次不能验证这两档合成成功，也不能据静态文档自动向登记请求添加未公开字段。

修复限定已确认的沧元声音克隆 profile：

- 主界面和画布对默认 Qwen3 / Chatterbox 使用原始语速，隐藏无效的语速调整，并提供中文说明。
- Adapter 对历史草稿自动注入的中性 `speed=1` 省略该字段；显式非 1 调整在调用前中文拒绝，不静默改变用户设置。
- 默认克隆引擎明确序列化为 `qwen3`；其他配音型号和其他厂商保持原有请求路径。
- ElevenLabs 保留文档范围，并提示音色兼容要求；已知音色不兼容错误汉化，仍保留上游状态与诊断代码。
- 请求失败不替换音色、不切换引擎、不自动再次提交。

新增 Adapter 行为测试覆盖默认引擎、历史中性语速、非 1 拒绝、ElevenLabs 边界及单次提交；画布渲染测试逐个覆盖四个克隆引擎。此次定向回归 56 项通过。完整检查与最终运行验证以交付记录为准。

本轮沿用现有 Contract、配音 Adapter 和共享 UI，无新增架构边界、兼容存储或任务 owner。上游未公开的 ElevenLabs 登记条件仍需服务商明确，不能将其描述为本轮已修复。

## 三维节点：画布图片引用

- 三维节点保留本地上传，同时支持点选画布中已完成的图片节点。选择后创建普通画布连线，并在对应参考图槽位显示源图缩略图和名称。
- 单图生成读取单图槽；多视角生成按正面、背面、左侧、右侧展示引用，箭头可交换相邻槽位。生成请求按换位后的视角映射提交，不复制节点图片 URL 到持久化草稿。
- 连线图片源变更后预览和请求会读取新图片；连线断开或图片删除后不回退到陈旧 URL。已清空的槽位保持空白。
- 画布本地地址、Blob、受保护的存储地址会经现有沧元媒体中转上传；同一张本地图片在多视角请求中只上传一次，上传失败会阻止生成。公开图片继续直传。
- 多图上传并发完成时按最新草稿合并，保留期间发生的视角排序、模型切换和提示词编辑。

测试覆盖图片节点连线、草稿序列化与规范化、源图变化/断开、多视角换位如何影响生成请求、本地中转和失败处理，以及面板控件行为。此前浏览器已验证单图和多视角点选/预览；刷新确认弹窗被取消以保留临时验收画布，因此**浏览器刷新后的实际恢复尚未验证**。
