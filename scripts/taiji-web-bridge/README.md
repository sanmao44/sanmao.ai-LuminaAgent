# 太极网页账号桥接

此桥接让 SANMAO 通过你已登录的太极聊天或绘图网页调用太极当前目录中的聊天和图片模型。它不使用 `api.aiyung.cn`、API Key 或充值接口，也不读取太极登录令牌。SANMAO 发出的消息或图片任务会进入太极网页，并由太极账户按网页显示的费用计费。

## 启动

在 SANMAO 仓库根目录运行：

```powershell
npm run taiji:web-bridge
```

浏览器打开 `http://127.0.0.1:8787/setup`，页面会显示一次性配对码。本机桥接只监听 `127.0.0.1`，生成的配对令牌保存在被 Git 忽略的 `.data/taiji-web-bridge/state.json`。

## 连接

1. 在 ScriptCat 打开 `http://127.0.0.1:8787/taiji-web-bridge.user.js` 并安装脚本。
2. 新开一个太极聊天标签页并保持登录；如果要调用图片模型，再额外打开一个太极绘图标签页（`/draw`）。两个页面都保持打开，脚本会按页面类型领取对应任务。
3. 脚本首次运行时，输入 `/setup` 页面上的一次性配对码。右下角显示“已配对”后，保持标签页打开。
4. 在 SANMAO 新增“其他兼容平台”连接：API 地址 `http://127.0.0.1:8787/v1`，访问密钥 `local-bridge`。测试连接并同步模型；聊天目录来自 `/api/chat/tmpl`，绘图目录来自 `/api/draw/template` 中当前明确启用的 GPT Image、Nano Banana、Midjourney 和 Niji 版本。选择模型后再在 SANMAO 中启用并发布。

桥接固定使用端口 `8787`；如果端口被占用，先停止占用它的本机服务再启动桥接。

## 行为边界

- 每次 SANMAO 调用都会在太极网页创建一个独立的新聊天会话，原有会话不会被追加内容。
- 图片请求通过太极绘图页的 `/api/draw` 创建任务，再轮询 `/api/draw/status/{taskId}`；完成后桥接下载白名单 CDN 图片并返回 OpenAI `b64_json`。绘图任务仍会保留在太极绘图记录中。
- 桥接启动时从已登录页面读取模型目录；聊天模型同步页面标价，绘图模型保留空价格并标为太极绘图，避免把计价表静态键误当成可用模型。余额接口未能验证，实际扣费以太极站点为准。
- 站点聊天只接受文本；SANMAO 传来的工具定义会被忽略，Taiji 不会执行本地工具。文件和图像输入会被拒绝。系统、用户和助手消息会按角色整理为一段文本，因此不是原生多轮 API 会话。
- 图片参考图、mask 和未列入桥接契约的参数会明确返回 `422`；图片结果只接受已确认的 Taiji CDN HTTPS 地址，避免把任意 URL 当作图片源。
- 网站 SSE 回复会被桥接成兼容的 OpenAI SSE，但桥接会等网页生成结束后再返回完整文本，不能逐 token 显示。
- 一次请求超时或结果未确认后不会自动重发；网页可能已经完成了生成。先检查太极聊天或绘图记录，再由你决定是否重试。
- 需要保持已配对、已登录的太极聊天或绘图标签页运行。聊天和绘图 worker 相互隔离，停止对应页面会只影响该类型的新请求。停止本地服务会中断新请求。

这不是太极官方 API。太极网站若更改聊天页面结构，浏览器适配器需要随之更新。
